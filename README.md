# МЧИМЫЧ — Клиент-серверная система курьерской доставки (Pet-проект)

Демонстрационный full-stack прототип экосистемы ресторанной доставки, спроектированный на основе реального опыта работы в логистике. Цель проекта — показать на практике построение отказоустойчивой клиент-серверной архитектуры, работу с REST API и обработку нестабильного сетевого соединения.

## Состав системы

1. **Android-приложение курьера (`android-app/`)** — нативный клиент на **Kotlin + Jetpack Compose** с локальным кэшированием и очередью отложенной синхронизации.
2. **Диспетчерская веб-панель (`web-dispatcher/`)** — SPA-интерфейс на **HTML5 / CSS3 / Vanilla JS** для создания заказов, распределения курьеров и мониторинга статусов в реальном времени.
3. **Backend & БД (`backend/`)** — REST API на **Google Apps Script + Google Sheets** с защитой от гонки потоков при пакетных запросах (`LockService`).

## Ключевые технические решения

* **Отказоустойчивая архитектура Offline-First:** при потере связи (например, в подъездах и лифтах) приложение не блокирует интерфейс. Смена статусов («На месте», «Завершить заказ») мгновенно фиксируется локально с точным временем устройства (`client_timestamp`) и попадает в очередь синхронизации (`SharedPreferences`).
* **Автоматическое восстановление и пакетная выгрузка:** системный слушатель `ConnectivityManager.NetworkCallback` отслеживает появление сети и автоматически отправляет накопленные события единым запросом `sync_events`.
* **Телеметрия и диагностика инцидентов:** в диспетчерской панели для завершенных заказов раздельно фиксируются фактическое время вручения по часам клиента, время получения пакета сервером и метка офлайн-синхронизации (`Synced from Offline Queue`). Предусмотрен сценарий эскалации при недозвоне гостю (`GUEST_NO_ANSWER` + таймер ожидания).
* **Интеграция с внешними сервисами:** передача маршрута в Яндекс Карты / Навигатор через Intent (`yandexmaps://` с fallback на `geo:` и веб-версию), живой посекундный таймер дедлайна.
